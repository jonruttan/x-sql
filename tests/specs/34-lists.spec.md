Lists: a value that holds values of one type, in order.

Expected output is DuckDB 2.0.0's own, taken from `duckdb -no-agent -c`, unless a case says otherwise.

## list values

### a list in brackets, of the type its elements all go into

```x
(sql "SELECT [1, 2, 3] a, ['x', 'y'] b, [1, 2.5] c, [1::TINYINT, 300] d, [1.5::DOUBLE, 2] e, [true, false] f, typeof([1, 2, 3]), typeof([1, 2.5])")
```
---
```output
┌───────────┬───────────┬─────────────────┬──────────┬────────────┬───────────────┬─────────────────────────────┬────────────────────────────┐
│     a     │     b     │        c        │    d     │     e      │       f       │ typeof(list_value(1, 2, 3)) │ typeof(list_value(1, 2.5)) │
```
