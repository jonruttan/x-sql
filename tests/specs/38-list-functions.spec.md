More of the list functions: a list's values once, lists beside lists,
a list cut, filled and picked from, and list_aggregate.

Expected output is DuckDB 2.0.0's own, taken from `duckdb -no-agent -c`, unless a case says otherwise.

## values once

### list_distinct is a list's values once each, the NULLs left out

DuckDB promises no order of the values, and its own is the order of a hash table; x-sql leaves each where it first stood. The cases sort them.

```x
(sql "SELECT list_sort(list_distinct([3, 1, 3, 2, NULL])), list_sort(list_distinct(['b', 'a', 'b'])), list_sort(array_distinct([[1], [1], [2]])), list_sort(list_distinct([1.5, 1.50, 2]))")
```
---
```output
┌────────────────────────────────────────────────────────┬─────────────────────────────────────────────────────┬────────────────────────────────────────────────────────────────────────────────────┬────────────────────────────────────────────────────┐
│ list_sort(list_distinct(list_value(3, 1, 3, 2, NULL))) │ list_sort(list_distinct(list_value('b', 'a', 'b'))) │ list_sort(array_distinct(list_value(list_value(1), list_value(1), list_value(2)))) │ list_sort(list_distinct(list_value(1.5, 1.50, 2))) │
│                        int32[]                         │                      varchar[]                      │                                     int32[][]                                      │                  decimal(12,2)[]                   │
├────────────────────────────────────────────────────────┼─────────────────────────────────────────────────────┼────────────────────────────────────────────────────────────────────────────────────┼────────────────────────────────────────────────────┤
│ [1, 2, 3]                                              │ [a, b]                                              │ [[1], [2]]                                                                         │ [1.50, 2.00]                                       │
└────────────────────────────────────────────────────────┴─────────────────────────────────────────────────────┴────────────────────────────────────────────────────────────────────────────────────┴────────────────────────────────────────────────────┘
```
