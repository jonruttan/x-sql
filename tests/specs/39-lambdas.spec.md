Lambdas, the list functions that take one, and list comprehensions.

Expected output is DuckDB 2.0.0's own, taken from `duckdb -no-agent -c`, unless a case says otherwise.

## list_transform

### a lambda is lambda, its parameter, a colon and an expression; list_transform answers it for each element

```x
(sql "SELECT list_transform([1, 2, 3], lambda x: x * 2), list_transform(['a'], lambda x: upper(x)), list_transform([1, NULL], lambda x: x + 1)")
```
---
```output
┌──────────────────────────────────────────────────────────┬───────────────────────────────────────────────────────┬──────────────────────────────────────────────────────────┐
│ list_transform(list_value(1, 2, 3), (lambda x: (x * 2))) │ list_transform(list_value('a'), (lambda x: upper(x))) │ list_transform(list_value(1, NULL), (lambda x: (x + 1))) │
│                         int32[]                          │                       varchar[]                       │                         int32[]                          │

└──────────────────────────────────────────────────────────┴───────────────────────────────────────────────────────┴──────────────────────────────────────────────────────────┘
```
