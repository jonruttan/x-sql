DATE, TIME, TIMESTAMP and INTERVAL: constants, casts, arithmetic,
comparison and columns.  There is no time zone.

Expected output is DuckDB 2.0.0's own, taken from `duckdb -no-agent -c`, unless a case says otherwise.

### arithmetic over rows

```x
(sql "CREATE OR REPLACE TABLE e (d DATE, ts TIMESTAMP, t TIME, n INTEGER); INSERT INTO e VALUES ('2026-01-31', '2026-01-31 23:30:00', '08:15:00', 1), ('2024-02-29', '2024-02-29 00:00:00.5', '23:59:59', 2), (NULL, NULL, NULL, 3); SELECT d + n, d + INTERVAL 1 MONTH, ts - d FROM e ORDER BY n")
```
---
```output
┌────────────┬────────────────────────────────────────────────────────────┬────────────┐
│  (d + n)   │ (d + to_months(CAST(trunc(CAST(1 AS DOUBLE)) AS INTEGER))) │  (ts - d)  │

├────────────┼────────────────────────────────────────────────────────────┼────────────┤
│ 2026-02-01 │ 2026-02-28 00:00:00                                        │ 23:30:00   │

│ NULL       │ NULL                                                       │ NULL       │
└────────────┴────────────────────────────────────────────────────────────┴────────────┘
```

### min and max, and a group by a date

```x
(sql "CREATE OR REPLACE TABLE e (d DATE, ts TIMESTAMP, t TIME, n INTEGER); INSERT INTO e VALUES ('2026-01-31', '2026-01-31 23:30:00', '08:15:00', 1), ('2024-02-29', '2024-02-29 00:00:00.5', '23:59:59', 2), (NULL, NULL, NULL, 3); SELECT min(d), max(ts), count(d) FROM e; SELECT d, count(*) FROM e GROUP BY d ORDER BY d")
```
---
```output
┌────────────┬─────────────────────┬──────────┐
│   min(d)   │       max(ts)       │ count(d) │
│    date    │      timestamp      │  int64   │
├────────────┼─────────────────────┼──────────┤
│ 2024-02-29 │ 2026-01-31 23:30:00 │        2 │
└────────────┴─────────────────────┴──────────┘
┌────────────┬──────────────┐
│     d      │ count_star() │
│    date    │    int64     │
├────────────┼──────────────┤
│ 2024-02-29 │            1 │
│ 2026-01-31 │            1 │
│ NULL       │            1 │
└────────────┴──────────────┘
```

### an INTERVAL column

```x
(sql "CREATE OR REPLACE TABLE w (i INTERVAL); INSERT INTO w VALUES ('1 day'), (INTERVAL 2 HOUR); SELECT i, DATE '2026-01-01' + i FROM w ORDER BY i")
```
---
```output
┌──────────┬──────────────────────────────────┐
│    i     │ (CAST('2026-01-01' AS DATE) + i) │
│ interval │            timestamp             │
├──────────┼──────────────────────────────────┤
│ 02:00:00 │ 2026-01-01 02:00:00              │
│ 1 day    │ 2026-01-02 00:00:00              │
└──────────┴──────────────────────────────────┘
```
